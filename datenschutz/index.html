Kontaktformular

Formulareingaben werden in dieser Version ausschließlich im geöffneten Browser verarbeitet. Sie werden nicht per Formular an Barthelmess übermittelt und nicht in einer Datenbank gespeichert. Wenn Sie die Anfrage speichern, erstellt Ihr Browser eine lokale Textdatei mit Ihren Angaben. Nach dem Neuladen werden die Formularangaben nicht wiederhergestellt.

Merkliste

Die IDs gemerkter Beispielmaschinen werden im lokalen Speicher Ihres Browsers abgelegt, damit Ihre Auswahl beim Seitenwechsel erhalten bleibt. Über die Merkliste können Sie jeden Eintrag entfernen. Es werden dabei keine Kontaktdaten gespeichert.
